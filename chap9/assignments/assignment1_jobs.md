# 과제 1 - 전면처리와 후면처리

PuTTY로 접속한 **일반 Bash 터미널에서 직접** 순서대로 실행한다.

```bash
sleep 100 &
sleep 100 &
jobs
ps -f
kill %1
ps -f
```

## 출력 결과 설명

1. `sleep 100 &`를 두 번 실행하면 100초 동안 기다리는 작업 2개가 후면에서 실행된다. 명령을 실행할 때 작업 번호와 PID가 출력된다.
2. `jobs`는 현재 셸에 등록된 두 작업을 보여준다. 처음에는 두 작업이 `Running` 상태이다.
3. `ps -f`는 현재 터미널의 프로세스 정보를 자세히 출력한다. 셸 프로세스와 `sleep` 프로세스를 확인할 수 있다. 실제 표시되는 PID는 실행할 때마다 달라진다.
4. `kill %1`은 첫 번째 작업에 SIGTERM 종료 신호를 보낸다. 별다른 신호 처리기가 없는 `sleep`은 종료된다.
5. 마지막 `ps -f`에서는 첫 번째 `sleep`이 사라지고 두 번째 `sleep`은 남아 있는 것을 확인할 수 있다. 종료 직후에는 프로세스 정리 시점에 따라 출력이 조금 다를 수 있다.

남아 있는 두 번째 작업을 끝내려면 `kill %2`를 입력한다.

`%1`, `%2`는 현재 **Bash 셸의 작업 번호**이므로, 앞서 다른 후면 작업을 실행했다면 실제 번호를 `jobs`로 먼저 확인한다.
